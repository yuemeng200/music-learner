# 视觉系统

## 1. 概念

视觉概念名为 **Sonic Atlas / 声音图谱**。界面像现代声音展览里的可操作仪器：信息清楚、材料克制、声音状态鲜明。它不是音乐节海报，也不是深色 DAW 仿制品。

标志性元素是“声波地平线”：一条贯穿工作台的实时曲线，在演奏、比较和播放时改变振幅与节点。它承担声音可视化和当前状态反馈，不作为无意义装饰。

## 2. 色彩令牌

- `canvas` `#E9E9E4`：矿物灰背景。
- `paper` `#F7F7F2`：阅读与说明表面。
- `ink` `#171918`：主文字与深色工作台。
- `muted` `#666A66`：次要信息。
- `cobalt` `#3155D9`：音高、选中和主动作。
- `coral` `#E45C3A`：节奏、播放头与警示。
- `signal` `#C7F06A`：实时声音与完成状态。

大面积只使用 `canvas`、`paper` 和 `ink`。功能色按音乐维度分工，避免单一蓝色界面。正文对比度不低于 WCAG AA。

## 3. 字体

- 中文展示与正文：系统中文黑体栈，优先 `PingFang SC`、`Noto Sans SC`。
- 拉丁展示：`Instrument Sans`；无法联网时回退到系统无衬线。
- 数据、频率、BPM、音名：`IBM Plex Mono`；回退到等宽字体。

标题不使用超大营销式字号。课程工作台主标题桌面端 36px，移动端 28px；正文 16px，数据标签 12px。字距保持 0。

## 4. 布局

桌面端采用 240px / minmax(0, 1fr) / 320px 三轨结构；中间实验区拥有最大视觉权重。页面不是卡片拼贴，主要区域以完整表面和分隔轨道组织。

移动端改为单列，实验区位于概念解释之前。固定控制条必须为底部内容预留安全区。所有固定格式控件使用明确的网格、宽高比或最小尺寸，避免播放状态引发布局跳动。

## 5. 形状与材料

- 页面区域圆角 0 到 8px。
- 仪器面板使用 1px 半透明高光和内阴影，模拟精密面板，而非玻璃拟态。
- 按钮圆角 4px；圆形只用于旋钮、播放和图标控制。
- 阴影极少使用，优先通过表面明度和细分隔线建立层级。

## 6. 动效

- 微交互 160 到 240ms，进入动效不超过 400ms。
- 使用 `cubic-bezier(0.22, 1, 0.36, 1)`，不使用线性移动。
- 按键按下产生 1 到 2px 的视觉压缩；声波从触发点传播。
- 播放头匀速移动属于时间编码，可使用线性；其他界面变化不得使用线性。
- 减少动态模式下关闭传播、入场与弹性，只保留必要的播放位置变化。

## 7. 文案与状态

界面使用动作语言：“听一遍”“移动这个音”“比较 A / B”“把它放回家”。不出现营销式功能说明。空状态直接给出下一动作，错误状态提供可重听的恢复路径。

## 8. 设计自检

- 第一屏必须直接呈现真实可操作的声音实验。
- 高级感来自排版、响应速度和状态细节，不来自装饰性渐变或大面积模糊。
- 每屏最多一个视觉主事件。
- 桌面、375px 移动端和减少动态模式均需截图验证。
