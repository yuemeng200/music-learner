# 项目执行简报

## 1. 最高目标

本项目要做的是一套面向大众的互动式音乐基础素养课程。它应像一门不可或缺的基础音乐课，但通过网页互动降低传统上课、读教材和理解抽象术语的成本。

课程的核心目标不是让用户记住大量名词，而是让用户对音乐基础理论建立感性的、可听见的、可操作的认知。用户应在完成课程后减少对音乐理论的抵触，理解音乐并没有想象中那么复杂，并能把基础概念连接成一个整体。

## 2. 用户完成课程后的状态

用户完成完整课程后，应能做到：

- 对音高、节奏、音程、音阶、和弦、调性、旋律、简单记谱有感性认知。
- 看到术语时能联想到具体听感和操作，而不是只知道定义。
- 能看懂非常简单的五线谱，知道五线谱为什么存在、表达了什么。
- 能用中英文术语识别核心概念，例如 interval、scale、chord、tonic、rhythm。
- 能使用课程最后提供的小型音乐编辑器，组合出一个非常短小的音乐片段。

最终创作不要求真正好听，也不要求专业完整。它的价值在于让用户把学过的基础材料亲手搭配起来，并实时听到自己的选择。

## 3. 课程立场

本课程定位为音乐美学与音乐素养的基础课程，服务于任何想接触音乐的人，包括：

- 想学乐器的人。
- 对音乐感兴趣但没有理论基础的人。
- 想进一步学习音乐理论的人。
- 想进入编曲、创作、作曲、音乐分析等领域的人。
- 只是希望更深入理解音乐的人。

它不绑定某一种乐器或某一种风格，也不以考试、考级或专业院校训练为目标。

## 4. 内容边界

### 4.1 需要覆盖

- 音高与频率。
- 音名、半音、全音、八度。
- 音程与听感。
- 音阶与调式基础。
- 和弦与和弦色彩。
- 调性中心与稳定感。
- 节奏、速度、重音、节奏型。
- 旋律轮廓、重复、变化、结束感。
- 简单五线谱识读。
- 最终小型音乐创作。

### 4.2 不需要覆盖

- 高阶和声学。
- 复杂转调。
- 复杂曲式分析。
- 专业作曲训练。
- 完整 DAW。
- MIDI 外设。
- 用户账号、后端 API、云同步。

## 5. 五线谱策略

五线谱需要出现在课程中，但不作为前期理解音乐的唯一入口。

策略：

- 前期以听觉、键盘、网格、声音可视化为主。
- 在用户理解音高、节奏和旋律后，引入五线谱。
- 只要求用户能看懂最基础的高音谱号、音符位置、时值和简单旋律。
- 五线谱的教学重点是“它为什么有用”，不是训练复杂读谱能力。

## 6. 术语策略

课程保留中文和英文术语。

原则：

- 主叙事优先使用中文。
- 英文术语以辅助标签、术语提示、括号或侧栏方式出现。
- 不让中英文术语堆满主界面。
- 术语必须在用户已经听过或操作过对应现象之后出现。

## 7. 最终创作工具

课程最后需要有一个非常小型、为本课程目标定制的音乐编辑器。

它不是专业制作软件，而是一个学习闭环工具。

建议能力：

- 选择一个音阶或调性中心。
- 编辑 1 到 4 小节节奏。
- 放置简单旋律音符。
- 选择或生成基础和弦。
- 实时播放当前片段。
- 可开关节奏、和弦、旋律层。
- 能用视觉方式显示用户使用了哪些课程概念。

用户完成最终创作时，应感到“我把这些概念真的用起来了”。

## 8. 交付要求

目标交付物是一个完整、可发布的纯前端产品。

需要包含：

- 完整课程体验。
- 高级、沉浸、艺术展览感的视觉设计。
- 响应式适配。
- 动效与声音反馈。
- 无后端 API 依赖。
- 可扩展的章节架构。
- 可运行的前端工程。

暂不需要：

- 部署配置。
- 后端服务。
- 登录注册。
- 云端数据。

测试视实现情况尽量完成；如果某些测试无法可靠覆盖，需要在最终说明中明确。

## 9. 技术授权

实现应使用纯前端 React，不使用 SSR 框架。

允许自主选择：

- 构建工具。
- CSS 方案。
- 音频库。
- 动画库。
- 字体、图像和视觉资源。
- 组件组织方式。

默认技术方向：

- React。
- TypeScript。
- 前端路由或内部状态路由。
- Web Audio 或 Tone.js。
- 课程内容数据化。
- 章节组件插拔式注册。

## 10. 架构要求

项目必须为后续扩展章节留出清晰空间。

要求：

- 课程章节应有独立目录或独立模块。
- 章节元数据、学习目标、步骤、术语、互动组件应尽量结构化。
- 通用互动能力应沉淀为共享组件，例如键盘、节奏网格、旋律编辑器、谱面视图。
- 新增章节时，应尽量只新增章节内容和必要的局部互动组件。
- 不追求把所有章节抽象成同一种模板，因为不同章节的交互天然会不同。

## 11. 视觉方向

整体应偏艺术展览，而不是传统网课平台。

关键词：

- 沉浸。
- 高级。
- 音乐可视化。
- 空间感。
- 精致。
- 愿意让用户停留和探索。

可以吸收音乐工作站、声音装置、数字艺术展、现代博物馆导览的气质，但必须保持课程清晰可用。

## 12. 自主决策授权

后续实现过程中，允许自主决定产品、课程、视觉和技术细节。

只要不偏离以下原则，就不需要反复请求确认：

- 音乐素养基础课程。
- 感性认知优先。
- 互动式学习。
- 高级沉浸设计。
- 纯前端。
- 可扩展架构。
- 最终有小型音乐创作闭环。
