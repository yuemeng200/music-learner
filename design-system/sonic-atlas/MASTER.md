# Sonic Atlas Design System

> 项目视觉规范的权威版本为 [`docs/VISUAL_SYSTEM.md`](../../docs/VISUAL_SYSTEM.md)。本文件用于设计 Skill 的分层检索。

## Direction

- Pattern: immersive learning workspace
- Concept: modern sound installation plus precise learning instrument
- Signature: a live wave horizon responding to every audible action
- Avoid: festival branding, playful red-orange palettes, glass decoration, generic course cards, DAW imitation

## Rules

- The first screen exposes a real sound interaction, never a marketing hero.
- Desktop uses a three-track learning workspace; mobile places the experiment first.
- Typography stays compact and instrument-like: 16px body, 28-48px page title, 10-12px utility data.
- Use color by musical dimension and pair color with shape, position, or text.
- Touch targets are at least 44x44px; keyboard focus and reduced motion are mandatory.
- Sophistication comes from layout, responsiveness, sound latency, and state detail, not decoration.
